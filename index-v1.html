AI와 함께하는 개발 프로세스

  1. 기획 및 분석서비스의 목적과 사용자 요구사항을 정의하고, AI를 활용해 경쟁 서비스와 기능 흐름을 분석합니다.
  2. 아키텍처 설계데이터베이스 구조, API 명세, 사용자 화면, 관리자 기능을 설계하고 개발 범위와 우선순위를 정합니다.
  3. 기능 구현AI 에이전트를 활용해 백엔드·프론트엔드·모바일 앱을 개발하고, 기능 간 데이터 흐름과 연동을 검토합니다.
  4. 테스트 및 검증빌드·린트·테스트를 수행하고, 주요 사용자 시나리오와 예외 상황을 직접 확인합니다.
  5. 배포 및 운영Docker와 GitLab CI를 활용한 배포 자동화, 앱 업데이트, 오류 점검과 운영 개선까지 관리합니다.

프로젝트별 개발 규칙과 의사결정 기록을 문서화해, AI 에이전트와의 작업에서도 일관된 코드 품질과 개발 기준을 유지합니다.

저를 소개합니다

저는 아이디어를 실제 서비스로 구현하는 풀스택 개발자입니다. Java와 Spring Boot를 활용한 백엔드부터 Next.js 기반 사용자 웹·관리자 시스템, Expo와 React Native를 활용한 모바일 앱까지 개발해 왔습니다.

화면과 기능을 만드는 데 그치지 않고, 데이터 구조와 API 설계, 인증·권한 관리, 배포 자동화, 운영 안정성까지 함께 고려합니다.

특히 한국과 몽골을 연결하는 서비스를 개발하며 다국어 환경, 현지 사용자 경험, 국제 거래와 물류처럼 실제 운영에서 생기는 문제를 해결해 왔습니다.

최근에는 Claude Code와 Cursor 같은 AI 개발 도구를 적극적으로 활용합니다. AI 에이전트와 함께 작업하되, 요구사항 정의, 아키텍처 설계, 기술적 의사결정, 결과 검증은 직접 수행합니다.

제 목표는 많은 기능을 만드는 것이 아니라, 사용자가 실제로 필요로 하고 안정적으로 쓸 수 있는 서비스를 만드는 것입니다.

기술 포인트와 스택
기술적으로 신경 쓴 부분
  • 안전한 앱 업데이트. 네이티브 코드가 바뀌면 스토어 배포가, 그렇지 않으면 OTA 배포가 필요합니다. 네이티브 지문(fingerprint)으로 OTA 가능 여부를 판정하고 번들을 사전 검증한 뒤 발행하도록 구성해, 스토어 심사 없이도 수정 사항을 안전하게 배포합니다.
  • 앱 버전 관리. 구버전 앱이 남아 있으면 기능과 API가 어긋날 수 있습니다. 관리자에서 최소·최신 버전을 설정하고 강제·권장 업데이트를 안내하도록 했습니다.
  • 반복 업무 자동화. 후기 요청, 홍보 기간 만료, 사용하지 않는 파일 정리 등 9가지 반복 작업을 스케줄러로 자동화했습니다.
  • 운영 보안과 안정성. 관리자 로그인 연속 실패를 차단하고, 회원 제재가 세션과 권한에 즉시 반영되도록 했습니다. 운영 중 발견한 동시성, N+1 쿼리, 데드락 문제도 점검해 수정했습니다.
  • 이미지 처리. 업로드 이미지를 WebP로 변환·리사이즈한 뒤 Cloudflare R2에 저장합니다.

  • 조회 성능. 데이터베이스 인덱스와 조회 쿼리를 최적화해, 10만 건 테스트 데이터 기준 주요 조회 응답 시간을 약 200ms에서 1ms 미만으로 단축했습니다. 인덱스는 서비스를 멈추지 않고 추가했습니다.
  • 인증 보안. 인증 요청을 IP당 분당 30회로 제한하고 계정별 실패 횟수도 제한해 무차별 대입 시도를 막습니다. 앱은 리프레시 토큰으로 로그인 상태를 유지합니다.
  • 배포 안정성. 배포 실패로 인한 서비스 중단 위험을 줄이기 위해 배포 후 헬스 체크를 수행하고, 오류가 나면 이전 Docker 이미지로 자동 복구하도록 구성했습니다.
  • 물류 연동. 쇼핑 주문을 택배 업무에 다시 입력하지 않도록, MisoCargo 파트너 API와 서버 간 연동해 주문을 택배 접수로 바로 넘깁니다.

  • 대량 매물 수집. 검색 결과가 1만 건까지만 조회되는 제한이 있어, 가격 구간을 나눠 조회하는 방식으로 전체 매물을 수집했습니다. 이후에는 스냅샷 비교로 바뀐 매물만 반영합니다.
  • 매물 수명 관리. 판매가 끝난 매물은 유예 기간을 둔 뒤 정리하되, 주문이 걸린 매물과 원본 데이터는 보존합니다. 주문 전에는 판매 여부를 즉시 다시 확인합니다.
  • 이미지 미러링. 외부 이미지 핫링크에 의존하지 않도록 매물 이미지를 Cloudflare R2에 다시 올려 제공합니다.
  • 몽골 세법 기반 도착가 계산. 연료·차종·고가 차량 소비세 규칙과 차종별 운임을 반영해 도착 총액을 계산합니다. 설정이 빠진 경우에는 ‘가격 준비중’으로 표시해 잘못된 견적이 나가지 않게 했습니다.
  • 신뢰할 수 있는 정산. 원장은 수정·삭제 없이 역분개로만 정정하고, 월 마감 스냅샷으로 지난달 숫자를 고정합니다. 주문·배정 상태 전이와 감사 로그를 서비스 전반에 적용했습니다.
  • 몽골어 글꼴 문제 해결. 몽골어 고유 문자(Ү, Ө)가 깨지는 문제를 키릴 확장 글꼴 서브셋을 추가해 해결했습니다.
